# Koeur Android + Supabase

La configuration publique Supabase est fournie dans `app/src/main/assets/supabase-config.json`.

Important : cette clé est une clé publique/publishable. Ne jamais ajouter une clé `secret` ou `service_role` dans l'application.

La version actuelle reste une démo Android tant que le code d'authentification, les requêtes PostgreSQL, Storage et Realtime n'ont pas été branchés dans l'interface. Le backend SQL Koeur V2 est fourni séparément.
