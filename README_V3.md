# Koeur V3

Cette version ajoute la messagerie liée aux matchs :
- liste des matchs
- ouverture d'une conversation
- lecture des messages
- envoi de messages
- réception temps réel via Supabase Realtime
- demande de certification
- Premium (écran de démonstration; paiement Google Play à configurer)
- profils et likes réels Supabase

Pour Realtime, activer la table `messages` dans Supabase Realtime.
Pour les photos, créer le bucket Storage et ajouter l'upload.
